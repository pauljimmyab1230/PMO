## Resumen Rápido

### Arquitectura
```
Frontend (React + TypeScript)
        ↓
   Backend (Node.js + Express)
        ↓
   Base de Datos (MySQL)
```

### Módulos del Sistema

1. **Inicio** - Charter, Stakeholders, Viabilidad
2. **Planificación** - WBS, Marco Lógico, Cronograma, Presupuesto, Riesgos
3. **Ejecución** - Actividades, Entregables, Issues
4. **Monitoreo** - Dashboard, Curva S, Indicadores
5. **Cierre** - Checklist, Lecciones
6. **Evaluación** - Medios/Fines, Encuestas
